This module adds a translatable Partner Address Details field on
partners for use in reports.

Documents are printed in the supplier’s language, but Odoo does not
provide a standard way to display a partner’s name and address in
multiple languages. This module addresses that limitation.

**Table of contents**

.. contents::
   :local:

Usage
=====

-  Go to the partner record.
-  Fill in Partner Address Details, including translations for the
   active languages.
-  Open a document linked to that partner and print the report (e.g., a
   Sales Order).

The contact information in the report will use the value from Partner
Address Details.
