Enable the feature by going to:

#. Go to menu *Settings* -> *General Settings* -> *Contacts*
#. Check the option "Keep Partner History".
#. Click Save.

If you want to allow users to edit the history address, you need to add the *Edit partner history address* permission by going to:

#. Go to menu *Settings* -> *Users & Companies* -> *Users*
#. Select the user you want to allow to edit the history address.
#. Go to the *Access Rights* tab.
#. Add the *Edit partner history address* permission.
#. Click Save.
