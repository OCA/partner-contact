This module replaces the kanban view of partner contacts with a list view, displaying
contacts with their roles in a more structured format. It provides a better overview
of contacts and their associated information.

**Table of contents**

.. contents::
   :local:

Usage
=====

To use this module:

1. Go to Contacts
2. Open a company or contact record
3. The contacts list will now be displayed as a list view instead of kanban view
4. You can see contact details including name, type, function, phone, email, and roles
5. The list is sortable and editable
