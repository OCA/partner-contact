Using phone numer you can get into the parter page directly.

You can type `&phone_number=123456789` in the end of the url of odoo webclient.

Example:
http://odoo.example.com/web#action=330&cids=1&menu_id=224&phone_number=123456789

OR you can simply type `/web#phone_number=123456789` after the domain name of odoo app.

Example: http://odoo.example.com/web#phone_number=123456789

Whether you type all the number or part of it, odoo will search and redirect you to the
most close results.
