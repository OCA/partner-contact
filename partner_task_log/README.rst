Use Cases / Context
===================

This module uses project tasks without a project as simple contact log
entries. That makes it possible to keep a structured history directly
from the contact, with assignees, tags, status, creation date, notes,
and chatter, without creating projects. Log entries are kept archived by
default so they do not appear mixed with regular project tasks or
personal private tasks.

Usage
=====

To manage a contact's task log:

1. Open a contact.
2. Click the *Task Log* smart button.
3. Create or edit log entries directly from the list view.
4. Use the *View* button on a row to open the full log entry form.

To review all contact log entries, go to *Project > Tasks > Task Log*.

Only log entries linked to the exact contact are displayed. Log entries
are project tasks without a project and without a parent task. They are
archived by default so they do not appear mixed with regular project or
private tasks.
