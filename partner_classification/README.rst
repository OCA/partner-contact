Use Cases / Context
===================

Organizations often need to assign customers to a single, well-defined
segment, such as:

- Specialist Retailer
- DIY
- Online
- Export

This classification acts as a control key for downstream logic such as:

- Pricing rules (e.g., EDI discounts)
- Unit of Measure behavior
- Reporting segmentation

This module only provides the classification structure.

Usage
=====

Assign a classification on a partner. The value will propagate to all
contacts under the same commercial entity.

Go to:

Contacts → Configuration → Classifications

Create classification records as needed.
