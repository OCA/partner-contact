This module allows to configure when to trigger an exception in case an
invalid IBAN is being put in the system.

Use Cases / Context
===================

Sometimes you would like to ensure that the IBAN that you have entered
in the partner bank settings is valid. However although Odoo has such
validation mechanism, it never triggers an exception. This is done
mostly to prevent possible exceptions when doing bulk partner data
import.

Configuration
=============

- Go to "Settings > Contacts" and activate the "Raise exception on
  invalid IBAN" checkbox.
- Use "Bank Countries" to validate only accounts of banks located in
  selected countries.
- Use "Partner Countries" to validate only partners located in selected
  countries.

Usage
=====

Put an IBAN into the partner bank account field. A validation error will
be raised if the IBAN validation fails.

When putting IBAN through code, use the "skip_iban_validation" context
key to skip the check programatically.
